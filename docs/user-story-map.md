# vote-reminder — User Story Map

## Product Goal

> 「投票日を知らなかった」をなくす。

ユーザーが一度だけ居住地域を登録すると、自分に関係する選挙を自動で判定し、投票日までリマインドする。

---

# User Story Map

## 1. 地域を登録する

### MVP

* 郵便番号を入力できる
* 郵便番号から自治体を特定できる
* 登録した地域を確認できる

### Next

* 住所を変更できる
* 登録地域を削除できる

### Future

* 複数地域を登録できる

---

## 2. 自分の選挙を知る

### MVP

* 登録地域に関連する選挙を取得できる
* 次回の選挙を表示できる
* 投票日を表示できる
* 選挙名を表示できる

### Next

* 衆議院議員選挙を表示できる
* 参議院議員選挙を表示できる
* 都道府県知事選挙を表示できる
* 市区町村長選挙を表示できる
* 都道府県議会議員選挙を表示できる
* 市区町村議会議員選挙を表示できる
* 補欠選挙・再選挙を表示できる

### Future

* 選挙種別でフィルタリングできる
* 過去の選挙を確認できる

---

## 3. 選挙を確認する

### MVP

* 選挙名を確認できる
* 投票日を確認できる
* 告示日・公示日を確認できる
* 投票までの残り日数を確認できる

### Next

* 投票時間を確認できる
* 投票所を確認できる
* 期日前投票の期間を確認できる
* 期日前投票所を確認できる

### Future

* 選挙公報を確認できる
* 候補者情報を確認できる
* 開票結果を確認できる

---

## 4. 投票日を忘れない

### MVP

* 投票日の通知を受け取れる

* 前日に通知を受け取れる
* 投票日当日に通知を受け取れる

### Next

* 通知のON/OFFを切り替えられる
* 通知タイミングを変更できる
* 選挙種別ごとに通知設定を変更できる

### Future

* 通知内容をカスタマイズできる

## 5. 投票する

### MVP

### Next

* 投票所の住所を確認できる
* 地図上で投票所を確認できる
* 投票所までの経路を確認できる

### Future

* 投票に必要な情報をまとめて確認できる

## 6. 投票後

### MVP

* 「投票した」と記録できる

### Next

* 投票済みの選挙を確認できる

# Core User Journey

```text
アプリを開く
    ↓
郵便番号を登録
    ↓
自治体・選挙区を特定
    ↓
自分に関係する選挙を取得
    ↓
「次の選挙」を表示
    ↓
投票日までカウントダウン
    ↓
7日前に通知
    ↓
前日に通知
    ↓
当日に通知
    ↓
投票所を確認
    ↓
投票
    ↓
「投票した」を記録
```

# MVP Definition of Done

以下を満たしたら `vote-reminder v0.1` とする。

* [ ] ユーザーが郵便番号を登録できる
* [ ] 郵便番号から自治体を特定できる
* [ ] 自治体に対応する選挙を取得できる
* [ ] 次回の対象選挙を表示できる
* [ ] 選挙名を表示できる
* [ ] 投票日を表示できる
* [ ] 投票までの日数を表示できる
* [ ] 7日前に通知できる
* [ ] 前日に通知できる
* [ ] 当日に通知できる
* [ ] 選挙情報を更新できる
* [ ] 選挙データの出典を保持できる
* [ ] 選挙終了後に通知対象から除外できる
