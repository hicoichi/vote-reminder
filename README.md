# vote-reminder

> 「投票日を知らなかった」をなくす。

郵便番号を一度だけ登録すると、自分に関係する選挙を自動で判定し、投票日までリマインドするアプリです。

## プロダクトゴール

居住地域(郵便番号)を登録するだけで、以下を自動的に行います。

1. 自治体を特定する
2. 対象となる選挙(衆院選・参院選・知事選・地方議会選など)を判定する
3. 次回の選挙の投票日・選挙名を表示する
4. 投票日までの残り日数と、期日前投票期間中かどうかを表示する
5. 投票日(デフォルトは7日前・前日・当日、設定変更可能)に通知する
6. 投票所・期日前投票所を確認できるようにする
7. 「投票した」ことを記録できるようにする

## 使い方

公開版: https://hicoichi.github.io/vote-reminder/

1. **(事前準備)** 選挙・投票所・期日前投票所のデータは自動取得されないため、まず選挙データ管理(`/#/admin`)から選挙・投票所・期日前投票所を登録しておく(本来は選挙管理者などが行うデータ整備を代行する画面)
2. トップページで郵便番号を登録すると、自治体が特定され登録地域の画面へ自動的に遷移する(以降、次回訪問時もこの画面が最初に開く)
3. 「ホーム」タブで、次回の選挙の投票日までの残り日数・期日前投票期間中かどうか・当日の投票所を確認する。関係する選挙が複数ある場合は「その他の関係する選挙」にまとめて表示される
4. 画面右上の歯車アイコンから通知タイミングの共通設定を、各選挙の「通知設定」ボタンからその選挙だけの個別設定を行う(個別設定があればそちらが優先される)
5. 投票したら、その選挙の「投票した」ボタンを押す。「ホーム」タブから消え、「投票済み選挙」タブに記録が残る
6. 登録した住所を変更したい場合は、「ホーム」タブ下部の「変更する」から郵便番号を登録し直す

## 開発状況

**本プロジェクトは試しに作るPoC(概念実証)であり、作り込みは行っていません。** 詳細は[.claude/CLAUDE.md](.claude/CLAUDE.md)を参照してください。

EPIC-01〜08のユーザーストーリーをVue 3のSPA(Single Page Application)として実装済みです。バックエンドは持たず、フロントエンドだけで完結する構成です。候補者・選挙公報・開票結果・選挙履歴(EPIC-09, 10)は将来スコープのため未実装です。

* 地域登録は1件のみを前提としています(複数地域の切り替えには対応していません)。
* データはブラウザの`localStorage`に保存します(サーバー・DBは持ちません)。
* 郵便番号から自治体を特定する処理は[zipcloud API](http://zipcloud.ibsnet.co.jp/doc/api)をJSONPで直接呼び出しています。
* 選挙・投票所・期日前投票所のデータは、外部連携ではなく管理画面(`/#/admin`)から手入力で登録します。当初は登録住所から選挙情報を自動取得するAPI連携を想定していましたが、そのような選挙情報を提供する公的APIが存在しないため、管理画面からの手入力で代替しています。

### 起動方法(ブラウザ操作)

Node.js 20以降で動作します。

```bash
npm install
npm run dev
```

起動後、表示されたURL(既定は http://localhost:5173 )をブラウザで開いてください。画面構成・操作の流れは[使い方](#使い方)を参照してください。

### ビルド

```bash
npm run build
```

`dist/`に静的ファイルが出力されます。バックエンドを持たないため、任意の静的ホスティングにそのまま配置できます。本リポジトリはGitHub Actions経由でGitHub Pagesに自動デプロイしています([.github/workflows/deploy.yml](.github/workflows/deploy.yml))。

### テスト

```bash
npm run test
```

`src/logic/`配下の業務ロジック(地域登録・選挙判定・通知・投票所・期日前投票・投票記録など)について、主要な正常系をVitestで検証しています。
